"Medidor de consumdo de água"

Desenvolvido por ![Douglas Arruda](https://img.shields.io/badge/Douglas_Arruda-red)

O objetivo deste programa é mostrar como está o consumo de água nas casas e comércio.
Primeiro o usuário digita qual o tipo de residência e qual o consumo de água em metros cúbicos.
O programa irá calcula se o consumo é econômico, moderado ou se está acima do limite

Programa desenvolvido em ![Python](https://img.shields.io/badge/Python-3.14-%233776AB?style=flat&logo=python&logoColor=white)
